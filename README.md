# 🔥 Gallo Negro

Sitio web institucional y catálogo de productos desarrollado para **Gallo Negro**, orientado a presentar la marca y sus productos de forma moderna, dinámica y autogestionable.

## 🚀 Características

- Sitio web institucional.
- Catálogo de productos autogestionable.
- Panel de administración.
- Diseño responsive.
- Interfaz moderna y dinámica.
- Gestión de información y productos.

## 🛠️ Tecnologías

- Laravel
- React
- TypeScript
- Tailwind CSS
- MySQL
